RHYTHIA-REIMAGINED v@@VERSION@@ - mod pack for Rhythia Legacy / Sound Space Plus nightly

Extract this zip INTO your game folder (the one with SoundSpacePlus.exe), then open ONE folder:

  With-Browser   everything, including "Browse": download maps from rhythia.com in the game
  No-Browser     everything except the online map browser

and double-click Install.bat in it. Updating: just run the new version's Install.bat
(no need to uninstall first). Switching between the two works the same way.
Uninstall.bat (in either folder) puts the original game back.
