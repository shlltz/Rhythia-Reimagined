RHYTHIA-REIMAGINED v@@VERSION@@ - ready-to-play Sound Space Plus (Rhythia Legacy) for Linux, with the mod pack built in

PLAY
  Native Linux build (x86_64) - no Wine or Proton needed.
  Extract this zip anywhere and run SoundSpacePlus.x86_64 (double-click it, or ./SoundSpacePlus.x86_64
  in a terminal). If it won't start: chmod +x SoundSpacePlus.x86_64
  Browse (sidebar cloud icon) searches and downloads maps from rhythia.com.
  Downloading Rhythia .rhm maps needs the "unzip" command (most distros have it).

YOUR DATA
  Maps, scores, replays and settings live in ~/.local/share/SoundSpacePlus - the same folder the
  official Linux Sound Space Plus uses, so if you already play, everything is there.
  Add maps: drop .sspm files into the Content Manager (sidebar +) or ~/.local/share/SoundSpacePlus/maps.
  Coming from Windows? Copy everything in %APPDATA%\SoundSpacePlus into that folder.

UPDATING
  Download the new Linux zip and replace this folder (your data is not in it).

WHAT'S IN IT
  See README-mods.txt for the full feature list.
  Customize > Storage (moving the user folder) is Windows-only.
