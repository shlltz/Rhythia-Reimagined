RHYTHIA-REIMAGINED (lite) v@@VERSION@@ - replay viewer, animations, star rating, customize panel, volume & visualizer
For Rhythia Legacy / Sound Space Plus nightly (Godot 3.6.2 build).

INSTALL
  1. Close the game.
  2. Extract this zip INTO your game folder (the one with SoundSpacePlus.exe),
     so you get  <game folder>\Rhythia-reimagined-lite-v@@VERSION@@\Install.bat
  3. Double-click Install.bat.
  A backup of the original game file is saved as SoundSpacePlus.pck.replaymod-backup.

UPDATE
  Close the game and run the new version's Install.bat - the old version is undone
  automatically (no need to uninstall first).

UNINSTALL
  Double-click Uninstall.bat (puts the original game scripts back).

If your game is a different version, the installer stops and changes nothing.

WHAT YOU GET
  Replays
    - "Replays" button in the sidebar: browse, search and watch your saved replays.
    - While watching:  SPACE pause | LEFT/RIGHT seek 5s (SHIFT 1s, CTRL 15s)
                       UP/DOWN speed 0.25x-2x | , . frame step | click/drag the bar to seek
                       H hide UI (press again to hide the whole HUD, for recording)
                       K hide keybind panel | ESC leave
  Animations
    - Dim moving topographic background + light mouse parallax on the map select menu.
    - Pages, map info panel and settings tabs slide/fade in.
    - Zoom-in transition when starting a map, osu!lazer-style loading screen with the map card.
    - Audio visualizer along the bottom of the menu (like the Rhythia rewrite).
  Star ratings
    - Star rating badge on every map in the list + on the song info / loading screen.
    - Restyled Content Manager (map import) as a step-by-step card.
  Volume
    - Alt + mouse wheel anywhere: osu!-style rings bottom-right (Master; hover Music/Effects
      to change those). 5% per notch, SHIFT for 1%.
  Extras
    - Small FPS improvements (HUD/cursor trail), visuals unchanged.
    - Hides the "Rhythia Rewrite" sidebar button and the version text.
