RHYTHIA-REIMAGINED v@@VERSION@@ - ready-to-play Sound Space Plus (Rhythia Legacy) with the mod pack built in

PLAY
  Extract this zip anywhere and double-click SoundSpacePlus.exe. Nothing to install.
  Browse (sidebar cloud icon) searches and downloads maps from rhythia.com.

YOUR DATA
  Maps, scores, replays and settings live in %APPDATA%\SoundSpacePlus - the same folder a normal
  Sound Space Plus install uses, so if you already play, everything is there.
  Add maps: drop .sspm files into the Content Manager (sidebar +) or %APPDATA%\SoundSpacePlus\maps.

UPDATING
  Download the new portable zip and replace this folder (your data is not in it),
  or run a newer Rhythia-reimagined patch zip's Install.bat inside this folder.

WHAT'S IN IT
  See README-mods.txt for the full feature list.
